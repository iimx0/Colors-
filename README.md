Colors

Colors- is a lightweight terminal tool written in C++ that displays a greeting message in the console with information about the current user, hostname, current directory, and special symbols in various formats.

The program is designed to run on Linux and Termux. It can be used to customize a personal bash prompt.

Core Ideas

Language: C++
Purpose: Display basic information (username, hostname, path) in the terminal
Platforms: Linux and Termux
Use Case: Shell prompt customization, usage in scripts and CLI utilities
Features: Simple configuration and clean output without unnecessary dependencies

Purpose

This tool was created for remote server administration, allowing an administrator to immediately see:

Which user account is currently active

Which server (host) they are connected to

Which directory they are working in

The program supports full prompt customization through a configuration file, providing flexibility for different workflows and environments.
